![GameTent](images/banner.png)

Game streaming for Jellyfin. Play the games on your server from Jellyfin apps.

**Status:** In development. Nothing to install yet.

## Part of Campground

GameTent is one of the [Campground](https://github.com/AHouseOfBards/Campground-Jellyfin) plugins for Jellyfin.

GameTent is written with assistance from artificial intelligence models, but is still primarily built, tested and maintained by me, Bards.
